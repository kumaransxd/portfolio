Vision Based Predictive Collision Avoidance
System for Navigation of MAV

This paper presents a vision-based predictive collision avoidance system for autonomous Micro Aerial Vehicles (MAVs). By integrating RT-DETR for real-time object detection and MiDaS for monocular depth estimation, the framework performs Time-To-Collision (TTC) analysis to predict risks. This lightweight, LiDAR-free approach leverages CV and AI to enhance safe and reliable UAV navigation in dynamic environments.
